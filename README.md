# astro-firebase

Firebase-integration packages for [Astro](https://astro.build), maintained as one pnpm/Turborepo monorepo.

| Package                                         | Version                                                                                                               | Description                                                                                                                           |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| [`@astro-firebase/hosting`](./packages/hosting) | [![npm](https://img.shields.io/npm/v/@astro-firebase/hosting)](https://www.npmjs.com/package/@astro-firebase/hosting) | Firebase Hosting CDN cache provider for Astro's [Cache Provider API](https://docs.astro.build/en/reference/cache-provider-reference/) |

## Installation

Install the package for the integration you need, e.g.:

```sh
pnpm add @astro-firebase/hosting
```

See each package's own README for setup and usage.
