## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five canonical roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: each package under `packages/<name>/` is its own bounded context with its own `CONTEXT.md` and `docs/adr/`; root `docs/adr/` holds system-wide/tooling decisions. See `docs/agents/domain.md`.
